# FIFA World Cup SQL Data Analysis

## Objective
This project leverages historical and 2022 FIFA World Cup datasets to explore patterns, team performance, and match outcomes using SQL. The goal is to extract meaningful insights from structured data covering multiple tournaments and player performances.

---

## Dataset Files

| File Name | Description |
|-----------|-------------|
| `2022_world_cup_groups.csv` | Group-wise breakdown of the 2022 World Cup |
| `2022_world_cup_matches.csv` | Match results and stats for 2022 tournament |
| `2022_world_cup_squads.csv` | Player details for all teams in 2022 |
| `international_matches.csv` | Historical international match records |
| `world_cup_matches.csv` | Matches from all past World Cups |
| `world_cups.csv` | Tournament summary data (host, winner, goals, etc.) |
| `data_dictionary.csv` | Schema and metadata for the datasets |

---

## Project Files

- `world cup sql.sql` – SQL file with all queries used in the analysis (basic to advanced)
- `world cup data analysis.pptx` – Final presentation containing SQL queries, result snapshots, and key insights.

---

## Analysis Overview

### Basic Insights
1. Total matches played in World Cup history
2. List of all World Cup-winning countries
3. Count of matches held in each tournament year
4. Total goals scored per World Cup

### Intermediate Insights
5. Average goals per match across all World Cups
6. Most successful teams (based on number of titles)
7. Top 5 goal-scoring players in the 2022 tournament
8. Number of matches hosted by each country

### Advanced Insights
9. Team rankings based on FIFA rankings for 2022 World Cup
10. Highest-scoring matches in World Cup history
11. Teams with the most final appearances
12. "Giant Killers" – Lower-ranked teams beating higher-ranked ones
