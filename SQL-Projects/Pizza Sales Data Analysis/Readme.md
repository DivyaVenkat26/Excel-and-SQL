# Pizza Sales SQL Analysis Project

## Objective
This SQL-based data analytics project explores sales, customer behavior, and revenue trends for a pizza business. By using multiple relational tables, we extract insights ranging from basic order metrics to advanced revenue analytics.

---

## Dataset Files

| File Name | Description |
|-----------|-------------|
| `orders.csv` | Contains unique order IDs and timestamps |
| `order_details.csv` | Maps each order to pizza types and quantities |
| `pizzas.csv` | Lists available pizzas with size and price |
| `pizza_types.csv` | Contains pizza names and their categories |

All datasets are in CSV format and structured as a relational database.

---

## Project Files

- `Pizza Sales Analysis.pptx` – Final presentation containing SQL queries, result snapshots, and key insights.
- `pizza_sales_data.sql`: All SQL queries organized by difficulty
---

## Project Tasks

### Basic Analysis
- Total number of orders placed
- Total revenue generated from pizza sales
- Highest-priced pizza
- Most common pizza size ordered
- Top 5 most ordered pizza types (with quantities)

### Intermediate Analysis
- Total quantity of pizzas ordered by category (join required)
- Hour-wise distribution of orders
- Category-wise distribution of pizzas sold
- Daily average pizzas ordered (grouped by date)
- Top 3 most ordered pizza types based on revenue

### Advanced Analysis
- Percentage contribution of each pizza type to total revenue
- Cumulative revenue trend over time
- Top 3 most ordered pizza types (by revenue) per category

---

## Key Insights
- The majority of orders are concentrated in evening hours.
- Certain pizza types (like Classic Pepperoni) dominate both in quantity and revenue.
- Medium size pizzas are the most preferred.
- A few pizza types generate a large chunk of the overall revenue — useful for marketing or menu design.
