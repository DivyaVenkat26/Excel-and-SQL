# Manufacturing Downtime & Efficiency Dashboard  

# Project Description  
    This project transforms raw manufacturing data into actionable insights using Excel. By leveraging Power Query, Pivot Tables, and data   visualization techniques, an interactive dashboard was developed to analyze downtime, identify operational bottlenecks, and improve        production efficiency.

# Skills Highlighted  
  Data Analysis  
  Excel (Pivot Tables, Pivot Charts, Power Query)  
  Data Visualization  
  Dashboard Design  
  Slicer Implementation  
  Data Transformation  
  Data Modeling (Merge Queries)  

# Project Highlights  

## Downtime Impact Analysis:  
  A calculated metric (Downtime × Factor) was created to evaluate downtime based on both duration and severity, enabling better prioritization of issues.  

## Data Integration using Power Query:  
  Multiple datasets such as production, downtime, and product details were merged using **Merge Queries** to create a unified dataset for analysis.  

## Issue-Level Analysis:  
  Visualizations highlight key contributors to downtime such as machine adjustment and machine failure.  

## Product & Flavor Insights:  
  Dashboard identifies products (CO-600, RB-600) and flavors contributing most to downtime, helping target process improvements.  

## Operator Performance Analysis:  
  Breakdown of downtime by operator reveals performance variations and potential areas for optimization.  

## Interactive Dashboard:  
  Slicers for product and issue enable dynamic filtering and user-driven analysis.  

## Clean & Structured Design:  
  Dashboard layout is designed for clarity, focusing on KPIs and key visuals for quick decision-making.  

## Impact  
    Provides a comprehensive view of downtime patterns and production efficiency. Helps identify critical issues, optimize operations, and   support data-driven decision-making in a manufacturing environment.
